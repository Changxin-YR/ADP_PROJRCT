先建立会话，再进入业务

  1. 获取 CSRFGET /api/v1/auth/csrf，保存会话 Cookie。
  2. 登录POST /api/v1/auth/login，写请求同时传 X-CSRF-Token。
  3. 读取身份GET /api/v1/auth/me，获取角色、能力码和数据范围。
  4. 执行业务写操作提交 expected_version；409 时读取最新数据。

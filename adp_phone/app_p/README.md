# ADP 微信小程序

本目录是 ADP 最新微信小程序源码，共 29 个页面，面向塘口现场快速作业。它与 Web、移动 App 共用 Flask API、权限和数据口径。

## 功能范围

- 工作台、投喂计划与记录、巡塘、用药、增氧等日常作业。
- 物料查询、领用、退库，塘口、分组、批次与历史。
- 消息、待办、个人作业历史、密码、离线状态、设置与关于。
- 移动会话令牌、Cookie/CSRF 连续性和本地离线队列。

## 开发者工具

1. 使用微信开发者工具导入本目录。
2. 将 `project.config.json` 中的 `touristappid` 替换为 ADP 小程序正式 AppID。
3. 登录具有该 AppID 开发权限的微信账号。
4. 根据部署环境修改 `utils/config.js` 中的 HTTPS API 地址并配置微信后台 request 合法域名。

本地源码检查：

```powershell
npm run check
```

# 明日手动验收操作手册

系统地址：`https://1.14.148.15`。所有步骤使用 [人工验收测试数据](03-人工验收测试数据.md) 中的现有记录；登录密码不写入文档，请使用已授权账号。

## 管理员业务链

### STEP-001 登录与工作台

- 使用账号/角色：`acceptance_admin`，系统管理员
- 菜单路径：登录页 → 工作台
- 前置条件：网络可访问系统地址。
- 操作：输入登录名和授权密码，点击“登录”。
- 预期页面结果：进入“今日工作台”；待办、消息、统计卡片均可加载。
- 数据验证：刷新页面后仍保持登录并能打开“待办”和“消息”。

### STEP-002 鱼塘组和塘口

- 使用账号/角色：系统管理员
- 菜单路径：塘口与批次 → 鱼塘分组；塘口与批次 → 鱼塘档案
- 操作：分别搜索 `ACCEPT-GROUP-01`、`ACCEPT-POND-001`、`ACCEPT-POND-002`；打开详情。
- 精确数据：`验收_东区成鱼塘组`、`验收_东一号塘`（12.5 亩、草鱼）、`验收_东二号塘`（8 亩、鲫鱼）。
- 预期页面结果：三条记录均显示已核验；东一号塘为养殖中。
- 数据验证：刷新并重复搜索，记录仍存在；继续搜索 `ACCEPTANCE-20260901-POND-01` 至 `...-04`，应有四条演示塘口。

### STEP-003 批次与存量

- 使用账号/角色：系统管理员
- 菜单路径：塘口与批次 → 养殖批次
- 操作：先搜索 `ACCEPT-BATCH-001`，再搜索 `ACCEPTANCE-20260901-BATCH-01`，分别进入详情并查看库存/台账。
- 精确数据：前者名称为 `验收_2026草鱼批次01`，关联 `ACCEPT-POND-001`，初始 20,000 尾 / 1,600kg；后者为 `[交付演示]草鱼养殖批次`。
- 预期页面结果：两条均为已核验；`ACCEPTANCE-20260901-BATCH-01` 当前存量显示 `900 尾 / 900kg`。
- 数据验证：刷新详情后两个批次的存量均不变化。

### STEP-004 物料、仓库与库存流水

- 使用账号/角色：系统管理员
- 菜单路径：物料与仓储 → 物料档案、仓库、库存台账
- 操作：搜索 `ACCEPTANCE-20260901-MAT-FEED` 和 `ACCEPTANCE-20260901-WAREHOUSE`；在台账搜索 `ACCEPTANCE-20260901-WH-RECEIPT`、`...-WH-ISSUE`。
- 精确数据：草鱼膨化饲料、综合仓库、入库 `100`、领料 `12`。
- 预期页面结果：物料已核验、仓库启用；流水分别显示 `+100` 与 `-12`。
- 数据验证：刷新台账，流水和余额保持一致。

### STEP-005 日常养殖作业

- 使用账号/角色：系统管理员
- 菜单路径：日常养殖 → 投喂计划、投喂任务、投喂记录、日常作业；塘口与批次 → 抽样、损耗、转塘、出塘
- 操作：逐页搜索以下单号并打开详情：`ACCEPTANCE-20260901-FEED-PLAN-VERIFIED`、`...-FEED-TASK-SUBMITTED`、`...-FEED-LOG-SUBMITTED`、`...-PROD-VERIFIED`、`...-PROD-SUBMITTED`、`...-LOSS-SUBMITTED`、`...-TRANSFER-SUBMITTED`、`...-HARVEST-01`。
- 精确数据：投喂计划每日 2 次、每次 12kg；任务 06:30；记录 06:45；出塘 100kg。
- 预期页面结果：状态分别显示已核验、待核验或草稿，详情关联同一批次和塘口。
- 数据验证：打开已核验记录时仅显示允许操作；刷新后状态不变化。

### STEP-006 采购、付款与应付

- 使用账号/角色：系统管理员
- 菜单路径：采购与付款 → 采购订单、应付、付款
- 操作：搜索 `ACCEPTANCE-20260901-PO-DRAFT`、`...-PO-SUBMITTED`、`...-PO-APPROVED`、`...-PAYMENT-01`、`...-PAYMENT-REV`。
- 精确数据：采购数量 100、单价 10、金额 1000；付款 400；冲销 100。
- 预期页面结果：草稿、待核验和已完成收货的订单状态区分正确；付款及冲销均有已核验状态和凭据。
- 数据验证：应付页面金额与付款、冲销记录可追溯对应。

### STEP-007 销售、交付与收款

- 使用账号/角色：系统管理员
- 菜单路径：销售与收款 → 销售订单、应收、收款
- 操作：搜索 `ACCEPTANCE-20260901-SO-DRAFT`、`...-SO-SUBMITTED`、`...-SO-APPROVED`、`...-SO-FULFILL`、`...-DELIVERY-01`、`...-RECEIPT-01`、`...-RECEIPT-REV`。
- 精确数据：销售草鱼 100kg，单价 20，订单金额 2000；交付关联 `ACCEPTANCE-20260901-HARVEST-01`。
- 预期页面结果：完成交付订单、已核验交付和已核验收款/冲销均可查看，交付数量与出塘数量一致。
- 数据验证：应收页面刷新后仍能显示对应销售单和收款关系。

### STEP-008 成本、资产和结算

- 使用账号/角色：系统管理员
- 菜单路径：成本与经营 → 成本结构、费用、资产、期间结算
- 操作：搜索 `ACCEPTANCE-20260901-ASSET-01` 和 `ACCEPTANCE-20260901-SETTLEMENT-01`，打开详情与历史记录。
- 精确数据：资产为增氧机；结算为七月结算。
- 预期页面结果：资产为已核验；结算状态为已冲销且原始记录可追溯。
- 数据验证：刷新页面，结算历史和资产字段保持不变。

### STEP-009 导入导出

- 使用账号/角色：系统管理员
- 菜单路径：数据交换 → 导入模板、批量导入
- 操作：下载物料模板；查看 `adp-import-normal-20260901.xlsx` 与 `adp-import-mixed-20260901.xlsx` 的导入记录；下载混合导入错误明细。
- 精确数据：正常导入 1/1；混合导入 1 行通过、1 行失败；导入物料 `ACCEPTANCE-IMPORT-MAT-001`。
- 预期页面结果：模板字段正常、导入结果与行数一致、错误文件可下载。
- 数据验证：进入物料档案搜索 `ACCEPTANCE-IMPORT-MAT-001`，应存在且为草稿。

### STEP-010 审计与账号管理

- 使用账号/角色：系统管理员
- 菜单路径：系统管理 → 用户管理、操作日志
- 操作：搜索 `acceptance_`；查看七个验收账号和与验收数据有关的操作日志。
- 预期页面结果：账号均为启用状态、角色名称正确；日志可按对象或时间筛选。
- 数据验证：刷新列表，账号和日志不丢失。

## 角色与范围复核

### STEP-011 财务人员范围

- 使用账号/角色：`acceptance_finance`，财务人员
- 菜单路径：采购与付款 → 应付；塘口与批次 → 鱼塘档案
- 操作：搜索 `ACCEPTANCE-20260901-PO-APPROVED`，再搜索 `ACCEPTANCE-20260901-POND-01`。
- 预期页面结果：可见应付与默认基地的验收塘口；不得出现系统管理菜单。
- 数据验证：手工输入 `/admin/users` 路径后不得取得账号管理数据。

### STEP-012 养殖管理员与作业员

- 使用账号/角色：`acceptance_breed_manager`、`acceptance_worker`
- 菜单路径：工作台 → 日常养殖；塘口与批次 → 批次/巡塘/投喂
- 操作：分别搜索 `ACCEPTANCE-20260901-FEED-TASK-SUBMITTED` 和 `ACCEPTANCE-20260901-PROD-VERIFIED`。
- 预期页面结果：养殖管理员可进行授权范围核验；作业员只看到允许执行的作业入口。
- 数据验证：两者均不能进入账号管理；个人范围不能查看非本人记录。

### STEP-013 仓储、采购与销售人员

- 使用账号/角色：`acceptance_warehouse`、`acceptance_purchase`、`acceptance_sales`
- 菜单路径：分别进入仓储、采购、销售模块。
- 操作：仓储搜索 `...-WH-RECEIPT`；采购搜索 `...-PO-SUBMITTED`；销售搜索 `...-SO-SUBMITTED`。
- 预期页面结果：各角色只看到本岗位菜单和授权操作，数据记录可正常加载。
- 数据验证：直接输入 `/admin/users` 不得取得系统管理能力。

完成每一步后都应刷新当前页面；数据应持续存在，状态与本手册一致。

## 三端覆盖缺口

### 移动 App

- `mobile/App.tsx` 仅提供单一工作台页面，只请求 `/api/v1/workbench/summary`。
- 缺少登录与会话、角色权限、塘口、投喂、仓储、采购、销售、成本、消息、离线队列及同步等文档要求的核心能力。
- 默认 API 地址为 `http://127.0.0.1:5000`，真实手机无法据此访问生产系统。

### 微信小程序

- `miniprogram/app.json` 只声明 `pages/workbench/workbench` 页面，`app.js` 默认 API 地址为 `http://127.0.0.1:5000`。
- 缺少登录、现场作业、物料领退、消息、历史数据、离线处理与同步等文档要求能力。
- 未配置生产 HTTPS 合法域名；真实微信客户端不能访问本机 HTTP 后端。

以上问题是产品实现缺失，无法通过验收脚本或小范围配置修改满足三端全流程需求。
